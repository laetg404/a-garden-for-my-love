# A Garden for my Love, Valbb ♡

*A little garden created with love, just for you.*

This project is a romantic animated field of tulips, created as a special birthday surprise for someone very important to me. It features colorful flowers gently swaying in the wind, a peaceful night sky, glowing fireflies, floating petals, and heartfelt messages.

More than just a coding project, it's a small way of turning code into something meaningful. ♡

## 🌷 Features

- **Animated tulips:** Colorful flowers gently moving with the wind.
- **Night sky:** A moonlit sky with twinkling stars.
- **Fireflies:** Small glowing lights floating around the garden.
- **Floating petals:** Petals drifting softly through the scene.
- **Personalized messages:** A sequence of romantic birthday messages.
- **Navigation controls:** Move forward and backward through the messages.
- **Responsive design:** Adapted to work on desktop and mobile browsers.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/laetg404/a-garden-for-my-love.git
   ```

2. Open the project folder:

   ```bash
   cd a-garden-for-my-love
   ```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.
